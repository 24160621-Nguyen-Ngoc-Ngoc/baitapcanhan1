# Cho Tôi Một Vé Đi Tuổi Thơ — Website cảm nhận sách

Website tĩnh được xây dựng bằng HTML/CSS, sẵn sàng triển khai trên GitHub Pages.

## Cấu trúc dự án

- `index.html` — Trang chủ và toàn bộ nội dung website.
- `favicon.svg` — Biểu tượng website.
- `.nojekyll` — Tệp cấu hình để GitHub Pages phục vụ website tĩnh.
- `README.md` — Hướng dẫn triển khai.

## Chạy thử trên máy

Mở `index.html` bằng Chrome, Edge hoặc Firefox. Không cần cài đặt phần mềm hay chạy lệnh build.

## Đưa lên GitHub Pages

1. Tạo repository mới tại https://github.com/new (ví dụ: `cho-toi-mot-ve-di-tuoi-tho`).
2. Upload toàn bộ các tệp trong thư mục này vào thư mục gốc repository.
3. Commit changes.
4. Mở **Settings → Pages**.
5. Trong **Build and deployment**, chọn **Deploy from a branch**.
6. Chọn branch `main`, thư mục `/(root)`, nhấn **Save**.
7. Đợi GitHub Pages triển khai, sau đó mở URL được hiển thị. URL thường có dạng:
   `https://TEN-TAI-KHOAN.github.io/cho-toi-mot-ve-di-tuoi-tho/`

## Lưu ý nội dung
